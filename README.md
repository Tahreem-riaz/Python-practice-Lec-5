
# 🐍 Lecture 05 — Loops in Python

A collection of Python practice exercises covering while loops, loop control statements, iteration over collections, the `range()` function, and practical loop-based applications, along with a hands-on mini project.

This repository contains my practice work for Lecture 05 of my Python learning journey. The lecture focuses on repeated execution using while and for loops, sequence generation with `range()`, navigating and searching standard Python collections, and controlling flow using `break`, `continue`, and optional `else` blocks.

---

## 🎯 Topics Covered

### 1. While Loops
* Condition-based repeated execution
* Loop counters, iterations, and accumulator patterns
* Avoiding infinite loops and handling termination conditions

### 2. For Loops & Range Function
* Definite iteration using `for` loops
* Generating number sequences with `range(start, stop, step)`
* Forward and reverse ranges
* Using the optional `else` block with loops

### 3. Iteration with Collections
* Traversing strings, lists, and tuples
* Searching, filtering, and data aggregation using loops
* Nested loops for multi-level data processing

### 4. Loop Control Statements
* Early loop termination using `break`
* Skipping iterations using `continue`
* Solving mathematical problems (Factorial, Sum of natural numbers)
